EZBulk for Wurm Unlimited - Fast item transfers that skip the dialogue menu.

 * Hold CTRL while dragging an item from a bulk container to transfer the entire stack
 * Hold SHIFT while dragging an item from a bulk container to transfer all similar items
 * Hold CTRL+SHIFT while dragging and item from a bulk container to transfer the entire content of the container to the desired container.
 * Press STOP OR MAIN MENU (escape by default) to stop the transfer.

Note:
Since this requires server communication for each individual transfer, transfers will feel slow, but are faster than doing the same thing manually,
and do not require your attention - so you can do other things while this happens.

Requires Ago's Client Mod Launcher.

Installation:
 * Download and install Ago's Client Mod Launcher if you haven't already
 * Download the latest release
 * Place the content of the "mods" directory in your "mods" folder
